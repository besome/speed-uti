# speed-ut
Esse projeto consiste em praticar o processo de um projeto cientifico, indo da avaliação dos dados, tratamento deles, verificação de indicadores e treinamento de um modelo preditivo/classificatório.

Esse pequeno projeto foi feito utilizando dados da MIMIC DEMO e parcialmente a MIMIC IV completa. Os dados da parte demo estão na pasta mimic-code/mimic-iv-demo. 
Os arquivos utilizados para tratamento dos dados, manipulação e criação e teste do modelo estão na mimic-code/analise.ipynb.

O modelo foi feito utilizando a biblioteca SLKLEARN, para isso foi utilizado o Classifier da biblioteca, que é um perceptron multilayer. Nesse projeto eu e minha dupla queriamos realizar um teste para ver como um modelo se sairia com dados generalizados e com poucos parametros. Ao final notamos que não obtivemos grande assertividade no modelo, mas foi um teste divertido e que acrescentou um grande conhecimento em nós.
